## Capability boundaries

Implemented in actual source: scoped intent/device tools and review screens, optional direct SIM call, SMS/WhatsApp composition, memory/aliases/feedback, MCP transport and permissions, Gemini proposals, local wake adapter/FGS, assistant role foundation/delegation, narrow accessibility navigation, diagnostics and privacy cleanup.

Explicitly unsupported: bypassing security/locking/CAPTCHAs; unrestricted universal app clicking; automatic permission grants; automatic personal WhatsApp/SMS sending; personal WhatsApp calling through an invented API; silent boot/process microphone restart; guaranteed 24/7 operation or free licensing/quota; native hardware DSP hotword access; automatic model training or self-modifying code; automatic quota/provider failover; scheduled communication replay; shared-developer-account Gemini backend; MCP OAuth/stdio/legacy transport/server sampling/complex schemas. Optional Porcupine requires its own user AccessKey and licensing/activation, separate from Google.

## Evidence levels

- Source implementation: present for supported capabilities above.
- JVM/local-network fixtures: actual results linked in verification/assistant; these are not real-device/live-provider checks.
- Instrumentation: APK compilation result is separate from execution.
- Real Android device, phone calls, messaging, role invocation, routes, native wake, accessibility, upgrades, UI and performance: NOT TESTED.
- Live Google/Picovoice/external MCP: NOT TESTED — no credentials/device.

Follow ASSISTANT-GUIDE.md before claiming release readiness. No production-ready or all-features-working claim is made. Current artifacts must match the verified source; APK signing keys and real credentials are never included.
